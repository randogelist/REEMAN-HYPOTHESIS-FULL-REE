# AWPI Phi/RH Lean — Rocq-matched v0.1.4

## Platform

Native Windows CMD. Do not use WSL for this package.

Pinned versions:
Lean 4.33.0
Mathlib v4.33.0

## Install

Install Git for Windows and Elan/Lean using the official Lean Windows installation instructions.

The included `lean-toolchain` pins Lean 4.33.0 automatically.

## Run

Extract the ZIP, open CMD inside the extracted folder, and run:

call run_complete.cmd

On the first run, Mathlib and its compiled cache are initialized.

If Windows reports error 740 while fetching the Mathlib cache, open CMD as Administrator and run `call run_complete.cmd` once. Later runs can use ordinary CMD.
